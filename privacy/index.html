Privacy

A minimal-data website.

The initial Yaksha site is designed to avoid invasive tracking and unnecessary data collection.

What is collected

The static site itself does not require user accounts or a database. Search runs locally in the browser using the published content index.

Third-party services

External services should be added only when necessary and documented in the site's configuration and privacy notice.

Future changes

If analytics, forms, community features or accounts are introduced, this page should be updated before those features are enabled.
