# Content model

The Markdown files in this directory are the reusable source content for the site's research-oriented sections.

Research fields:
`title`, `slug`, `description`, `date`, `author`, `category`, `tags`, `difficulty`, `readingTime`, `featured`, `status`

Lab fields:
`title`, `slug`, `difficulty`, `skills`, `status`, `researchLink`

Challenge fields:
`title`, `slug`, `difficulty`, `estimatedTime`, `skills`, `status`

Field Note fields:
`title`, `slug`, `tags`, `readingTime`

Learning Path fields:
`title`, `slug`, `level`, `topics`
