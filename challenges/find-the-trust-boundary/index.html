Research Challenge / Intermediate

Find the Trust Boundary

Given a small cloud architecture, identify the path by which a low-privileged identity could reach a sensitive resource.

Cloud Security · IAM · Architecture·Estimated time: 45–90 min

Scenario

A small fictional environment contains enough evidence to answer the challenge, but not enough to remove the need for reasoning.

Starting Evidence

architecture.txt timeline.log events.json notes.md

Questions

  1. What is the most important trust boundary?
  2. Which observation is strongest evidence?
  3. What alternative explanation should be ruled out?
  4. What control would break the attack path?

Optional Hints

Hint 1

Start with identities and trust relationships before focusing on tools.

Hint 2

Build a timeline and distinguish cause from consequence.

Solution

Reveal solution

The intended solution is an evidence-based explanation of the trust boundary, the sequence of actions, and the defensive control. The challenge deliberately rewards reasoning rather than tool-specific memorization.
