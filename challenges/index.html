03 / Challenges

Research problems, not just flags.

Not every security problem has a flag. These challenges are designed around investigation, reasoning, and evidence.

Intermediate

Find the Trust Boundary

Given a small cloud architecture, identify the path by which a low-privileged identity could reach a sensitive resource.

Cloud Security · IAM · Architecture
Intermediate

What Did the Attacker Leave Behind?

Given Windows logs and a timeline, reconstruct the attack and identify the strongest pieces of evidence.

Windows · Forensics · Timeline
Intermediate

The Suspicious Pipeline

Given a repository and CI workflow, identify the security weakness and explain the trust boundary it crosses.

CI/CD · GitHub Actions · Secrets
Intermediate

Firmware Evidence

Given an extracted firmware filesystem, identify sensitive information and insecure implementation choices.

Firmware · Embedded Linux · Reverse Engineering
Advanced

Detect the Attack

Given network and endpoint telemetry, identify the attack sequence and explain which observations support your conclusion.

Detection · Network Telemetry · Endpoint Telemetry
